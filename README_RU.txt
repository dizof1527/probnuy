РАСПИСАНИЕ БАШГАУ — 2026-11-23.1

В меню сайта появился «Аккаунт». У регистрации, входа и восстановления пароля отдельная страница. Все новые аккаунты получают роль «Ученик». Администратор может переключать роли «Ученик» и «Преподаватель» в списке пользователей.

Чтобы изменить занятие, войдите администратором, выберите группу и неделю, затем откройте карточку пары и нажмите «Редактировать пару». В этой версии правка действует в выбранной неделе. Кнопка «Вернуть исходную пару» отменяет правку. Расписание доступно гостям, а сохранённые правки есть и в офлайн-копии.

УСТАНОВКА НА GITHUB PAGES

Загрузите index.html, sw.js, account.html, account.js, supabase-client.js, schedule-cloud.js и папку vendor с сохранением путей. Роль первого администратора и схема в проекте Bgau-class уже настроены. Файл в supabase/migrations предназначен для установки схемы в другом проекте. Подключение в браузере использует только публичный ключ.

В Supabase Auth настройте Site URL на https://bgau-class.ru и добавьте точный Redirect URL https://bgau-class.ru/account.html. Включите Allow new users to sign up и оставьте подтверждение e-mail. Для писем учащимся вне команды Supabase подключите SMTP. Инструкции доступны на https://supabase.com/docs/guides/auth/redirect-urls и https://supabase.com/docs/guides/auth/auth-smtp.
