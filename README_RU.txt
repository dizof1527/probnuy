РАСПИСАНИЕ БАШГАУ — 2026-11-23.4

При первом посещении страницы аккаунта выберите язык. Доступны русский, английский, французский, испанский и португальский. Во время заполнения формы можно сменить язык в шапке. Поля анкеты и правила профиля переведены. ФИО вводится по-русски, кириллицей.

Для расписания нужен аккаунт. На первом шаге регистрации укажите почту, пароль, имя и фамилию. На втором выберите курс, группу и подгруппу. Отчество и псевдоним можно оставить пустыми. В настройках аккаунта можно изменить анкету, загрузить или убрать аватар. Для группы без деления на подгруппы сайт сам выберет «Без подгруппы».

Почту, анкету, аватар и счётчики видит администратор. В разделе «Управление пользователями» можно назначить преподавателя, вернуть роль ученика, заблокировать и разблокировать доступ. Пароль меняется через восстановление доступа. В топе показываются до пяти псевдонимов. Повторные открытия в течение 30 минут считаются одним посещением. День считается по времени Уфы. Счётчики начинают собираться при открытии этой версии расписания.

В опубликованном приложении для открытия расписания требуется интернет. Авторизованный пользователь может скачать HTML-файл расписания через меню офлайн-доступа и открывать сохранённый файл без сети.

ПУБЛИКАЦИЯ

В Supabase Auth укажите Site URL https://bgau-class.ru и добавьте Redirect URL https://bgau-class.ru/account.html. Включите Allow new users to sign up и выключите Confirm email, чтобы почта сохранялась для входа и новый пользователь сразу получал сессию. Восстановление пароля продолжает использовать почту. Для отправки писем восстановления учащимся нужен SMTP. Инструкции Supabase доступны на https://supabase.com/docs/guides/auth/redirect-urls и https://supabase.com/docs/guides/auth/auth-smtp.

Схема профилей и исходное расписание уже подготовлены в проекте Bgau-class. После проверки регистрации опубликуйте файлы этой версии на GitHub Pages и примените 202611230003_bgau_enforce_registration.sql, чтобы закрыть общедоступное чтение правок через API. Исходное расписание загружается через Supabase в закрытую схему. Для установки на чистый проект понадобятся все миграции и отдельная загрузка каталога групп и расписания. Старое расписание уже публиковалось открыто и остаётся в истории Git и в ранее скачанных копиях.

ПРЕДЫДУЩИЙ ВЫПУСК — 2026-11-23.1

В меню сайта появился «Аккаунт». У регистрации, входа и восстановления пароля отдельная страница. Все новые аккаунты получают роль «Ученик». Администратор может переключать роли «Ученик» и «Преподаватель» в списке пользователей.

Чтобы изменить занятие, войдите администратором, выберите группу и неделю, затем откройте карточку пары и нажмите «Редактировать пару». В этой версии правка действует в выбранной неделе. Кнопка «Вернуть исходную пару» отменяет правку. Расписание доступно гостям, а сохранённые правки есть и в офлайн-копии.
